Screen Studio 中文安装器

怎么用：
1. 解压后，双击“Screen Studio 中文安装器”。
2. 先保存录制/剪辑工作并退出 Screen Studio，然后点“检查并安装”。
3. 如果 macOS 弹出管理员验证，由你本人输入电脑密码或使用 Touch ID。
4. 安装完成，点“打开 Screen Studio”。如果软件要求录屏或辅助功能权限，按安装器里的“权限帮助”完成系统授权。

不需要 AI、终端、Python，也不需要把密码给别人。
安装器自动检查版本、备份原版、安装中文界面。以后需要撤销时重新打开安装器，点“恢复原版”。请保留安装器和备份。

当前只适配：Apple Silicon（M 系列）Mac、macOS 13 或更新、官方签名和文件指纹匹配的 Screen Studio 4.1.0-5005。
不同版本或已经被改动的应用，会停止安装。补丁不含 Screen Studio 软件或授权。

首次打开可能遇到的系统提示：
这个安装器目前尚无 Apple Developer ID 签名和公证。如果 macOS 提示无法验证开发者，请确认文件来自发布者后，在“系统设置 → 隐私与安全性”查看是否提供“仍要打开”，由你本人决定是否允许。
如果系统明确报告恶意软件、文件损坏，或企业策略不允许，则停止使用，不关闭系统保护。
Apple 官方说明：https://support.apple.com/zh-cn/102445

汉化会改变 Screen Studio 的代码签名，系统可能要求重新授权；它仍有自己的版本和授权限制。文件安装通过不等于录屏测试通过，建议先录几秒并导出检查。

本包是非官方的限定版本兼容性试用包。安装器不会自动重置隐私权限，不读取账号/密码或上传数据，不保证所有设备和在线功能兼容。
